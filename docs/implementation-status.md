- Android APK：GitHub Actionsの[実行 #4](https://github.com/AyameTetsuya/fonix-app/actions/runs/41357246782)でビルドとArtifacts保存に成功。対象ソースは`204aad1`。成果物は`fonix-family-debug-apk`（75.7MBのZIP、内容は`app-debug.apk`）。これは実機での成功を意味しない。

## 残りの手順

1. 環境設定で通信許可の変更を保存・公開し、Flutter SDKの取得を再開する。
2. ローカルでも`flutter pub get`、`flutter analyze`、`flutter test`を実行できるようにする。これらはCIでは通過済み。依存ロックは依存解決後に保存する。
3. 作成済みAPKを使い、Fire両実機でマイク許可・拒否、再生、保存、削除、中断復帰、オフライン、画面と所要時間を検証する。
4. 仮音声・単語・IPA・説明・口と舌の図をレビューし、必要な素材を差し替える。
5. 要件15.1に従って児童音声で評価方式を検証する。基準を満たす対象だけに助言を有効化する。
6. 提供者の条件・費用を確認し、端末登録・同意・接続を整えてオンライン評価を接続する。

上記の必須条件を満たすまでは、要件定義書の初期版受入が完了したとは扱わない。
