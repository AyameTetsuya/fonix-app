# 発音練習と自動評価の比較・検証計画

監査日: 2026-11-11。対象: 日本語を主に話す 6 歳・9 歳、Fire HD 10 第 11・13 世代。これは導入の承認資料であり、モデル・サービスの導入、児童音声の収集・外部送信を行った記録ではない。

## 推奨する初期商品

当面は、同梱お手本の再生 → 自分の声を録音 → 交互に聴く、という現在の端末内練習を採用する。録音できたこと、練習したことに報酬を出し、音量・録音時間・波形から「発音が正しい」「最後の音が出ていない」と判定しない。マイクを使わなくても島・仲間を解放できる設計を維持する。

最新のユーザー指示は、科学的・技術的に十分検証できなければ録音と聴き比べにとどめることを認めている。旧 `requirements.md` の初期版自動評価要件より本方針を優先する。自動評価がないことだけを録音練習版の発売阻害要因とはしない。ただし、未実装の「発音採点」「発音を直す AI」を販売文句にしない。

## 実装の現状と重大度

| 重大度 | コードで確認した事実 | 商品上の扱い |
| --- | --- | --- |
| 高 | `lib/platform/device.dart` の `RecordingResult` は録音時間 250 ms、RMS 0.008、クリッピング比率 0.1 を使う。音素識別器はない | 録音品質の目安に限定する。しきい値も Fire 実機で未検証 |
| 高 | アプリから呼ばれるのは Android の録音・再生用 MethodChannel。ASR、発音モデル、評価 API の呼び出しはない | 現在のアプリは自動採点対応とは説明できない |
| 高 | `server/assessment.py` に Azure 用の単語評価試作はあるが、`server/reviewed_targets.json` は空。アプリとは未接続 | 試作コードの存在は精度、契約、稼働、専門家監修の証拠ではない |
| 中 | 試作サーバーは同意フラグ、端末トークン、対象語の審査、音声品質検査、利用枠を持つ | サーバー内のフラグだけで保護者への説明・同意取得が完成したとはいえない |
| 中 | 保存は明示操作、既定は一時録音。Android はバックアップを無効化し、アプリ休止時に一時録音の破棄を試みる | 実機で中断・クラッシュ・権限拒否・削除を試す。削除失敗を含め実挙動は別途検証 |

RMS は音声と生活音を区別できない。大きい音でも英語とは限らず、小さい録音でも発音は適切かもしれない。「よく聞こえなかった」は機器側の不確実性として伝える。

## 選択肢

以下の工数は相対評価で、見積額・実機ベンチマークではない。「オフライン可」は実装可能性を表し、現在のアプリに組み込み済みという意味ではない。

| 案 | 分かること・分からないこと | オフライン / Fire | 費用と実装負担 | 判断 |
| --- | --- | --- | --- | --- |
| A: 現在の録音・聴き比べ | 聴覚的な自己比較を支える。自動的な正誤判定はしない | 現行 Android 実装あり。機内モード実機試験が必要 | API 従量費なし。お手本の品質確保、使いやすさ、端末試験が主な費用 | **初期版の推奨** |
| B: 端末内の録音品質検査 | 無音・短すぎる録音・クリッピングの疑い。音素や語末子音の正誤は分からない | 現行の時間・RMS・クリッピング検査を利用可能 | API 従量費なし。端末・距離・騒音別の校正が必要 | 録音補助として使う |
| C: Vosk 等の小型 ASR | 何と認識したか。目的語が出ても発音全体の正しさは保証しない | Vosk 公式 README はオフライン・Android 対応を記載。特定モデルの Fire 速度・児童精度は未測定 | ランタイム、モデル、辞書のライセンス確認、容量・電池・ネイティブ統合・精度実験が必要 | 認識を発音採点に置き換えない。導入は承認後の調査 |
| D: Whisper / whisper.cpp | 文章・単語の転写。孤立した `/s/`・`/ʃ/` の教育評価は確認できていない | whisper.cpp に Android/iOS の実行例あり。Fire 2 機種の速度・メモリ・発熱は未測定 | C/C++ 統合、モデル同梱、量子化別の精度再検証。モデルの大きさだけで動作保証できない | 初期版には入れない |
| E: 強制アラインメント、GOP 等の音素評価 | 既知の台本と音の対応・尤度。台本を与えれば誤発音でも位置を割り当てる場合がある | 適切な音響モデルと実装があれば端末内の可能性。現在は未調査・未計測 | 音素辞書、許容変異、児童向け音響モデル、評価校正、専門家付きコーパスが必要 | 語末音等の具体助言には研究開発が必要 |
| F: Azure 等のオンライン発音評価 | ベンダーの語・音素スコア。単語と孤立音の対応範囲、児童の助言精度は別途確認 | 通信必須。電波のない場所では A/B へ戻る | 利用単位・単価・最低料金・リージョン・保存/学習利用・通信費・運用監視を契約前に確認 | 比較・明示承認が済むまで接続しない |

Whisper は言語モデルの文脈で誤音を目的の単語に補正することも、話していない文字列を出すこともあると公式モデルカードが説明する。したがって単語一致率、ASR の confidence、WER（単語誤り率）をそのまま発音点や教育的助言の正確さとみなせない。Vosk も公式には音声認識のツールであり、README に日本語母語児の英語発音評価の妥当性は示されていない。

母語話者成人の平均 ASR 成績、別言語の認識成績、端末内で動くという事実は、本アプリの 6 歳・9 歳への教育的妥当性を直接示さない。個々の候補をこの児童集団で比較する必要がある。

## 孤立音と単語を分ける

`s`、`sh` を単独で伸ばす練習と、`sun`、`ship` を読む練習は別タスクとする。文字名、音素、単語を異なる対象 ID で管理し、単語用 ASR を孤立音に流用しない。破裂音を不要な母音付きにする、語末の `/t/` に必ず強い破裂を求めるなど、特定の教材音だけに合わせた判定を避ける。許容される英語の変異は音声専門家が定義する。

最初に検証するとすれば、長い単語や文の総合点ではなく、専門家が判別可能性を確認した少数の対立音を対象にする。ただし音素・教材の選択自体が未承認であり、この監査では変更していない。

## 公平性と検証手順

これは実験仕様の提案であり、効果が確認された研究結果ではない。学習効果の根拠は `research-evidence.md` を参照する。

1. **専門家による正解の定義**: 英語音声学、児童の音声、日本語母語話者の英語に詳しい確認者と、何を許容し、何を助言対象にするかを音ごとに定義する。米国英語の許容変異、加齢・歯の生え替わり・話速による差を考慮し、医療的な診断に使わない。
2. **保護者に説明した別の調査**: 研究協力者、用途、保存場所・期間、削除方法、外部処理の有無を明示して同意を得る。現在のアプリ利用から音声を自動で集めない。参加しなくても学習機能に不利益を設けない。
3. **参加者と条件**: 6 歳付近と 9 歳付近を分け、日本語話者の英語経験、声の高さ、許容発音の幅、Fire 第 11/13 世代、マイク距離、静かな部屋/生活音を含める。他年齢・母語への一般化は別検証とする。家庭の 2 名だけで商品一般への妥当性を結論しない。
4. **独立した教師ラベル**: 2 名以上がモデル結果を見ずに評価し、一致度と不一致の裁定を記録する。「正しい/誤り」に加え「録音から判断できない」を残す。成人による不自然な物まねだけで児童の誤りを代用しない。
5. **参加者単位の分割**: 学習・しきい値調整・最終試験の話者を分ける。同じ子の別録音、同じ録音の増強版を試験側へ漏らさない。対象音、単語内位置、孤立音を別に集計する。
6. **計測**: 誤訂正率 = 許容された発音へ誤った助言を出した数 / 専門家が許容した試行数。助言適合率 = 正しい具体助言数 / 出した具体助言数。これに見逃し率、判定保留率、遅延、録音失敗、RAM・電池・発熱を併記する。判定保留を大量に出して見かけの成績を上げていないか、全試行ベースで確認する。
7. **不確実性**: 年齢・音・端末別の分母と 95% 信頼区間、子ども単位でのばらつきを報告する。同じ児童の多数録音を独立な多数例とみなさない。旧要件の「正しい音 50 例で誤訂正 5% 以下」だけでは十分でない。独立 50 例で誤訂正 0 でも、二項分布の両側 95% 正確信頼区間の上限は約 7.1% で、5% 以下を確立したとはいえない。
8. **事前の合否判定**: 旧要件の誤訂正 ≤5%、助言適合率 ≥90%、判定可能率 ≥70% は暫定の商品基準であり、確立した研究標準ではない。サンプル数と区間推定、各群の最低性能、保留条件を専門家と事前に決める。総合平均だけで 6 歳群の不利益を隠さない。
9. **子どもへの提示**: 判断できないときは「お手本をきいてみよう」。助言は 1 点、再挑戦の案内は 1 回まで、その後進める。採点を進行・報酬・動物のお世話の条件にしない。検証に合格した具体助言だけを使う。

自動判定が教育上役立つかも別の問いである。短期的なモデルスコア上昇だけでなく、未学習語・別話者の聴き分け・後日の保持・子どもの自信を、聴き比べのみの条件と比較する。これは今後の検証案であり、現時点でこのアプリの効果は未実証である。

## データ・費用・ライセンスの承認条件

- 端末内モデルであっても導入前に比較案を提示する。ランタイムとモデル重み、辞書、音素ラベル、変換済み重み、追加ライブラリの利用・再配布条件を別々に記録する。Vosk ランタイムの Apache-2.0 は全 Vosk モデルのライセンスを保証しない。Whisper 公式はコードと重みを MIT と説明するが、配布する具体ファイル・改変・通知・依存ライブラリの確認は残る。
- オフラインを宣言する機能は、初回も必要なモデルを同梱する。追加ダウンロード前提なら、その部分を「初回ダウンロード後はオフライン」と明示する。勝手な初回ダウンロードやバックグラウンド通信は追加しない。
- オンライン案は送信内容、識別子、リージョン、保存/削除、AI 学習利用、第三者処理、ログ、規約上の児童利用、料金単位、上限、障害時の動作を保護者向け比較資料にする。ベンダーの最新公式契約を読めるまでは「保存されない」「学習に使われない」と断定しない。
- 保護者によるサービス導入の承認と、利用者ごとの説明・同意・マイク許可は別に必要。PIN を入力できたことだけで外部送信への説明済み同意とはみなさない。接続回復時に既存録音を自動アップロードしない。
- 買い切りに継続クラウド費用を無制限に含めない。試作 `Quota` の月 1,000 円、予約 10 円等の値は仮の枠で、実課金見積ではない。機能を販売する前に、利用分数 × 契約単価に加え、サーバー・監視・保存・サポート・税等の費用を計算し、制限と継続提供条件を明示する。
