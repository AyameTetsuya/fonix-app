# 学習ロジック・教材参照のコード監査

監査日: 2026-11-11。基準コミット: `3f447d9`。作業ブランチ: `audit/phonics-learning-product-readiness-20261111`。

対象は `lib/domain/curriculum.dart`、`lib/domain/learning.dart`、その回帰テスト、および出題から参照する同梱教材。Androidの録音・通信・UIの実機品質は、この文書の静的確認だけでは判定しない。

## 判定

教材参照と出題に限定した範囲でP0は見つからなかった。P1の出題不具合があり、限定修正を加えた。未導入文字の選択肢、混合レッスンの設計、定着指標などの未解決点が残るため、一般公開できる完成教材とは判定しない。音声・IPA・意味・発音図の専門家による監修も未完了。

P1は学習目標や出題の公平性を大きく損なうもの、P2は記録・将来の教材更新・学習体験を損なうものとして区別した。修正していない点は、受け入れ済みの仕様変更と扱わない。

## 保存互換性と変更境界

- 保存スキーマは1のまま。完了レッスン、スター、ごはん、仲間、PIN、録音、保護者設定、過去の解答・学習回を削除・再計算しない。
- 10島・70レッスンの構成、導入順、教材ID、既習判定と子音連結の導入時点を変更しない。
- 発音の自動採点や新しいモデル、外部音声サービスを追加しない。録音品質と発音の正しさを同一視しない。
- `canBlend()` は教材内部の整合性検査であり、録音の発音評価ではない。IPA連結が一致したことも、音源の正確性や子どもの読みの習得を保証しない。

## 回帰検証

`test/learning_test.dart` に次を追加した。

1. 不明な音IDを明示的に拒否すること。
2. 子音連結6レッスンで対象の語頭・語末を持つ既習語が出ること。
3. `/u/` の文脈別5語は分解再生不可、`cat/ship/stop/hand/cake/rain/cute` は可能で、`g/ɡ` の字形差は許容すること。
4. 同じIPAまたは同じ表示の誤選択肢を二つ提示しないこと。
5. 島3の確認で島2の固定5語を繰り返さず、新しく読める確認語を出すこと。
6. 全10確認レッスンが5問、既習範囲、重複しない語、同じ教材に対して再現可能な順序を保つこと。

`test/app_test.dart` にも6語の回帰を追加。上記5語で分割ボタンがなく、`cute`では分割音が再生でき、全6語で単語のお手本・保護者音量・保存値が維持されることを確認する。
