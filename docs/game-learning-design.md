# 短い冒険と学習の設計案

更新：2026-11-11。対象：日本語を主に話す6歳・9歳、各自のFire HD 10。既存の4画面、キャラクター、10島70課、保存スキーマ1を前提にする。画面・キャラの全面改修や、保存履歴の意味の変更を指示する文書ではない。

目的は、文字と音の対応を知り、習った規則で初めての語を解読し、音を聴き比べ、発話を練習できること。冒険・仲間・ごはんは、その学習を続けやすくする手段とする。利用時間やスター数を能力の証拠にしない。

**3〜5分、復習最大2問、発音練習の再挑戦案内1回は、保護者の希望に基づく設計仮説である。研究で最適と実証した値ではない。** [研究監査](research-evidence.md)は原典取得が阻まれており、教育効果の検証は未完了。

## 1. 現状・今回の修正・提案を区別する

| 区分 | 内容 | 完了したと扱わないこと |
| --- | --- | --- |
| 現実装 | 大きい出発ボタン、地図、仲間、おとの図鑑。既習の復習最大2問、文字音・単語の選択／組み立て、録音・聴き比べ。完了で進行・ごはん、節目で仲間を解放。IPA表示は任意 | 純粋な音素意識の測定、初見語の音読評価、発音自動採点、ゲーム内の行動と学習課題の一体化、学習効果の実証 |
| 今回の限定修正 | 島の確認で新しく読める語を優先、子音連結の対象語を選ぶ、同音・同表示の選択肢重複を避ける、不明な音IDを検出。文脈と合わない音の分解再生を抑止する整合性判定を追加 | 教材の増補、未習選択肢の解消、混合課の再設計、全音源・図解の正確性。検証結果は[コード監査](code-learning-audit.md)で別記 |
| 次段階の提案 | 下記の短い物語、目標に対応する達成表示、技能別の観察。まず既存画面・IDのまま教材と表示を小さく試す | この文書だけで実装・採用済みにしない |
| 承認待ち | 課題・学習順の大幅変更、新しい履歴項目と移行、外部サービス／評価モデル、児童音声の調査利用・外部送信、専門家への正式依頼 | 契約・有料利用・収集・送信・スキーマ変更をこの提案から開始しない |

今回の限定修正は既存の出題不具合への対応であり、下記のゲーム設計全体を実装するものではない。既存の完了、スター、ごはん、仲間、設定、録音、解答履歴は保持する。

## 2. 1回の流れ

例は`sh`を学ぶ回。「橋をわたって仲間に会う」という短い目標で、音を聴き、対応する綴りを選び、既習範囲の語へつなげる。物語のための長文、時間制限、操作の速さによる採点は追加しない。

| 段階 | 子どもの操作・見せ方の提案 | 学習と進行の条件 |
| --- | --- | --- |
| 出発・目標 | いつもの仲間と出発。`sh`と耳の絵、短い「きく」。説明は音声で任意に聴く | 新出は原則1〜2対応。IPAを読めなくても開始できる。EDU-01・10 |
| 思い出す | 橋の入口で既習の音・語を最大2問。答えを見る前に一度選び、その後にお手本 | 未習内容は復習にしない。復習がたまっても延長しない。初回には無理に復習を作らない。EDU-09 |
| 試す | 例：`/ʃ/`を聴いて綴りを選ぶ→既習なら`ship`を音ごとにつなぐ→別の対応を短く確認。1操作ごとに橋の足場が増える | 橋の進行は練習完了に対応。誤答は短い比較とお手本を示して進める。未習の誤選択肢や絵の正解ヒントを使わない。EDU-02〜06 |
| 声にする | 耳・マイク・ヘッドホンの既存操作で、聴く→まねる→任意に聴き比べる。「もういちど」は1回案内 | 録音なしでも進める。音量や録音成功から正しい発音と認定しない。EDU-07・08 |
| 達成を見る | 仲間に到着。「やったね！」と、その回に行ったことを絵と一言で示す。例：`shで あそんだ` | 星・ごはんは完了へのごほうび。1回の正解で「発音できた」「習得した」と表示しない。EDU-11 |
| 選んで終わる | 「なかま」から任意にごはん・なでる、またはホームへ。次の冒険を自動開始しない | お世話しなくても不利益なし。いつでも終了でき、未利用で動物が病気にならない。EDU-11・12 |

本体は3〜5分を目安に、目標・復習約1分、試す活動約1〜2分、発話約30〜60秒、達成約15〜30秒を初期案とする。初期の既習音が少ない回は短くてよい。問題数を満たすために未習内容や無関係な語を足さない。お世話・図鑑の自由探索は任意の別時間とし、目安を超えても時間切れにしない。

確認レッスンは既存の原則5問を維持する。未練習語の解読、別収録の聞き分けを確認する提案は、使える教材と課題を監修してから試す。確認に失敗しても次の島を閉じず、次回の短い復習へつなげる。

## 3. 「何ができたか」を混ぜずに見せる

子どもには、その回に実行した活動と、複数回の自力確認で裏付けられた達成を分ける。保護者には課題・初回解答・援助の有無・未確認を示す。横断的な総合点や「英語力レベル」にまとめない。

| 技能 | 確認すること・達成表示の提案 | 現実装の記録と不足 |
| --- | --- | --- |
| 音素意識（PAの一部） | 文字なしで音を結合・分解できるか。例：`ship`は`/ʃ/ /ɪ/ /p/`。達成候補は「おとを つなげた」 | 独立した課題・指標はない。文字並べの正解で代用しない。EDU-03 |
| 文字音・文字名・大小文字 | 音→綴り、綴り→音、文字名、大小文字を別確認。自力正解とお手本後を区別 | `Attempt`の技能・方向はあるが、文字名等を十分に独立測定していない。EDU-01・06 |
| 初見語の解読 | 習った対応で、練習に出していない語を読めるか。音読、選択、組み立てを別評価。達成候補は「べつの ことばも よめた」 | `heldOut`は確認用教材の区分で、実際の初見を保証しない。選択の正解を音読成功にしない。EDU-02 |
| 聞き分け | 文字を使わない音の比較と、音→文字の選択を区別。別収録でも比べられるか | 通常の音選択は文字知識と同じファイルに依存する。聴覚だけの識別を習得済みにしない。EDU-05 |
| 発話・録音 | お手本、録音、聴き比べを行ったか。達成表示は「こえを きいた」等の実行事実に限る | 録音を伴う発話は`speaking`・正誤なし。録音品質は発音評価ではない。スキップを実施済みにしない。EDU-07・08 |
| IPA | 任意に記号と音を照合する。図鑑を開く・音を聴くことと、記号を読めることを分ける | 表示設定と図鑑あり。独立した習得確認はなく、冒険の進行条件にしない。EDU-10 |

現状のスター・島の解放は「完了」の表示として維持する。「じぶんでできた」等の技能達成を追加する場合は、違う課題・後日の自力確認を含む判定条件を先に決める。録音・IPAは読む技能の達成へ加算しない。

既存`Attempt.direction`では組み立て等を十分に分離できず、学習回との対応や確認語の露出履歴も不足している。過去データを新指標に読み替えない。追加指標が必要な案は、移行・互換性のレビューと承認まで紙の観察票で試す。今回スキーマは変更しない。

## 4. 家庭2人で短く試す

各児童を別々に、まず通常の短い回を1回ずつ観察する。保護者は開始後の説明を控え、困ったら助け、助けた場所を記録する。無理に続けず、本人がやめたら終了する。続けたい場合のみ別日に同じ流れを数回試す。

観察票は「開始・再生・選択・発話スキップ・終了を一人でできたか」「読まないと止まる場所」「聴こえ方」「本体の所要時間」「疲れ・拒否」「本人が選んだ次の行動」を短く残す。正解率と操作上の迷いを分け、子ども同士のランキングにしない。EDU-10〜12。

学習確認を行うなら、少数の未練習語と別収録の音を別枠で用意し、即時と後日を分ける。7日後は観察計画の仮値である。専門家監修前の語・音で成績を断定しない。家庭の`n=2`は操作性と個人内の変化を観察するためであり、ゲーム設計の効果や他児童への一般性を実証するものではない。

## 5. 外部公開前の評価

1. [研究監査](research-evidence.md)の原典・国内児童EFLの未充足を解消し、適用範囲と不確実性を更新する。教材・音源・IPA・図解・混合課の目標は[専門家レビュー](experts/)と照合する。
2. Fire第11・13世代で音量、マイク拒否、中断・終了・再開、オフライン、保存・削除を確認する。家庭2人以外の対象年齢にも操作性を試す場合は、保護者の説明・同意と子どもの参加意思を別途確認する。
3. 教育効果を公表するなら、未練習語、別収録、後日の保持を含む比較可能な評価計画を先に作る。知覚・産出・解読と動機・利用時間を分け、必要な対象者数や専門家評価を計画する。数値や期間を研究結果として先取りしない。
4. 自動助言は[発音評価の比較案](pronunciation-evaluation-options.md)の精度・誤訂正・保留・費用・データ条件を別途評価する。検証前のASRや音量を発音点にせず、発売時の機能説明は実際に提供する範囲に合わせる。

公開可否はコードやAPKの完成だけで決めない。今回の文書と限定修正では、教育効果、教材監修、両実機での成功、外部サービス導入の承認を完了したとは扱わない。
